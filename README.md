# 자산 로드맵 (라이트)

가계부, 주식, 목표, AI 재무 상담을 한 화면에서 관리하는 개인용 웹앱입니다.
설치나 회원가입 없이 주소만 열면 바로 쓸 수 있어요.

## 할 수 있는 것

- **기록** — "점심 9천원, 택시 1만2천원"처럼 말하듯 적으면 수입·지출로 정리합니다. 날짜를 골라 지난 기록도 넣을 수 있어요.
- **자산** — 주식·ETF를 종목코드와 함께 등록하고 계좌(일반/ISA/연금저축)별로 봅니다. 현금·예금과 부채도 적어둘 수 있어요.
- **목표** — 목표 금액과 기간을 정하면 순자산 기준으로 얼마나 왔는지, 매달 얼마씩 모으면 되는지 보여줍니다.
- **예산** — 한 달 예산을 정하면 홈에서 남은 금액을 바로 확인합니다.
- **AI 상담·분석** (선택) — 무료 Gemini 키를 넣으면 재무 상담, 주간·월간 분석, 주식 현재가 확인을 쓸 수 있어요.

## 처음 쓰는 법

1. 사이트를 열고, 폰이라면 공유 버튼 → **홈 화면에 추가**를 누르면 앱처럼 쓸 수 있어요.
2. (선택) AI를 쓰려면 [aistudio.google.com](https://aistudio.google.com)에서 **Get API key**로 무료 키를 받아 **더보기 → 설정 → AI 연결**에 붙여넣습니다.
3. **자산** 탭 → **자산 수정**에서 보유 주식, 현금·예금, 목표를 입력합니다.

## 주식 현재가

- 자동으로 바뀌지 않습니다. **자산 → AI로 확인**을 누르면 AI가 최근 종가를 찾아 제안하고, 확인한 뒤 골라서 반영합니다.
- AI 없이 쓰려면 **자산 수정**에서 현재가를 직접 입력하세요.
- 국내 종목코드는 네이버 금융에서 이름 옆 6자리(예: 삼성전자 005930), 미국주식은 티커(예: AAPL)를 넣고 매수가는 원화로 적습니다.

## 데이터는 어디에 저장되나요?

- 모든 기록은 **지금 쓰는 기기의 브라우저에만** 저장됩니다. 서버로 보내지 않아요.
- 기기를 바꾸거나 브라우저 데이터를 지우면 사라지니, **설정 → 내보내기**로 가끔 백업하세요. 새 기기에서는 **가져오기**로 불러옵니다.
- 백업 파일에는 AI 키가 들어가지 않습니다. 새 기기에서는 키를 다시 입력하세요.
- AI를 쓰면 상담·분석에 필요한 기록 요약이 Google(또는 선택한 게이트웨이)로 전송됩니다.

## 직접 배포하기 (GitHub Pages)

1. GitHub에서 새 저장소를 **Public**으로 만듭니다.
2. **Add file → Upload files**로 `index.html`을 올리고 **Commit changes**를 누릅니다.
3. **Settings → Pages**에서 Source를 `Deploy from a branch`, Branch를 `main` / `/(root)`로 두고 **Save**를 누릅니다.
4. 1~2분 뒤 `https://<아이디>.github.io/<저장소이름>/` 주소로 열립니다.

AI 조언은 참고용이며 특정 상품의 매수·매도를 권유하지 않습니다.
